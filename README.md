# TableFile

**TableFile** è un'applicazione nativa per macOS che permette di convertire, modificare, condividere e organizzare i file attraverso un'interfaccia a menu radiale, direttamente dal Finder.

Basta trascinare un file per visualizzare automaticamente un menu circolare con le operazioni disponibili, senza dover aprire applicazioni aggiuntive.

## Funzionalità

### Conversione dei file
- **Immagini:** PNG, JPG, HEIC, TIFF, GIF, BMP e PDF.
- **Video:** MP4, MOV, M4A e ulteriori formati con FFmpeg.
- **Audio:** M4A, WAV, AIFF, FLAC e altri formati con FFmpeg.
- **PDF:** conversione in immagini PNG/JPG ed estrazione del testo.
- **Documenti:** conversione tra DOCX, RTF, HTML e TXT.

### Strumenti integrati
- Compressione e ridimensionamento delle immagini.
- Rotazione, ritaglio e ribaltamento delle immagini.
- Compressione di video e PDF.
- Unione e divisione dei PDF.
- Unione di file audio e video.
- Elaborazione di più file contemporaneamente.

### Gestione rapida
- Condivisione tramite AirDrop.
- Copia e spostamento dei file.
- Copia del percorso negli appunti.
- Apertura del Terminale nella cartella del file.

### Interfaccia macOS
- Menu radiale che appare automaticamente durante il trascinamento.
- Interfaccia che si adatta allo spazio disponibile sullo schermo.
- Supporto alla modalità chiara e scura.
- Supporto opzionale a Liquid Glass su macOS 26 e successivi.
- Applicazione accessibile direttamente dalla barra dei menu.

## Download

**[Scarica TableFile.dmg](./TableFile.dmg)**

### Installazione

1. Scarica il file `TableFile.dmg`.
2. Apri il file DMG.
3. Trascina **TableFile.app** nella cartella **Applicazioni**.
4. Apri TableFile dalla cartella Applicazioni.

### Importante: prima apertura su macOS

Al primo avvio, macOS potrebbe impedire l'apertura dell'applicazione mostrando un messaggio di sicurezza.

Per autorizzare TableFile:

1. Prova ad aprire **TableFile** dalla cartella Applicazioni.
2. Se macOS blocca l'apertura, seleziona **Fine** o chiudi l'avviso.
3. Apri **Impostazioni di Sistema**.
4. Vai su **Privacy e sicurezza**.
5. Scorri verso il basso fino alla sezione **Sicurezza**.
6. Fai clic su **Apri comunque** accanto all'avviso relativo a TableFile.
7. Conferma l'operazione selezionando **Apri** e, se richiesto, autenticati.

Dopo questa procedura, TableFile potrà essere avviata normalmente dalle Applicazioni.

Il pulsante *Apri comunque* viene visualizzato dopo un tentativo di apertura bloccato da macOS.

Per ulteriori informazioni: [Supporto ufficiale Apple](https://support.apple.com/it-it/102445).

## Come utilizzare TableFile

1. Avvia TableFile. L'applicazione rimarrà disponibile nella barra dei menu di macOS.
2. Apri il Finder e seleziona uno o più file.
3. Inizia a trascinarli con il mouse o il trackpad.
4. Il menu radiale di TableFile apparirà automaticamente vicino al cursore.
5. Sposta il cursore sull'operazione desiderata e rilascia i file per eseguirla.

Le operazioni disponibili cambiano automaticamente in base alla tipologia di file selezionata.

Se trascini il cursore fuori dal menu radiale, questo si chiude e puoi continuare normalmente il trascinamento.

## Requisiti di sistema

- **Sistema operativo:** macOS 13 Ventura o successivo.
- **Installazione:** tramite file DMG.
- **FFmpeg:** opzionale, necessario per alcune conversioni audio e video avanzate.
- **Liquid Glass:** disponibile su macOS 26 e successivi.

## Note

TableFile sfrutta le tecnologie native di macOS per integrarsi con il Finder e offrire un'esperienza semplice e immediata.

Le conversioni che generano nuovi file vengono salvate nella cartella del file originale, evitando di sovrascrivere eventuali file già presenti.
